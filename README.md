# MatildaRate

Небольшой hi-tech редактор тир-листов без сборщика и сторонних зависимостей.

## Запуск

Для чтения редактируемого каталога `tierlists.json` запусти HTTP-сервер из папки проекта:

```powershell
python -m http.server 8000
```

Открой `http://localhost:8000`. Если открыть `index.html` двойным щелчком, приложение всё равно запустится с резервным каталогом фруктов, но изменения JSON браузер не прочитает.

## Как добавить свой тир-лист

Открой `tierlists.json` и добавь объект в массив `categories`:

```json
{
  "id": "games",
  "name": "Игры",
  "emoji": "🎮",
  "items": ["Hades", "Portal 2", "Minecraft"]
}
```

У каждого списка должен быть уникальный `id`. Цвета, подписи и числовые веса уровней находятся в массиве `tiers`. В текущем интерфейсе показывается первая категория файла — переставь свою категорию на первое место, чтобы открыть её.

Прогресс хранится локально в браузере (`localStorage`).
